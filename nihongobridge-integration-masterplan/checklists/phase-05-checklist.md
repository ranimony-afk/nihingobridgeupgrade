# Phase 05 — SRS & Review Checklist

## Gate Requirements

All mandatory items must pass before proceeding to Phase 06.

---

## Deck Management
- [ ] Decks can be created
- [ ] Decks can be edited and deleted
- [ ] Deck settings work (new cards/day, limits)
- [ ] Deck listing works

## Card Management
- [ ] Cards can be created from vocabulary
- [ ] Cards can be created from kanji
- [ ] Cards can be created from grammar
- [ ] Custom cards can be created
- [ ] Card front/back display correctly
- [ ] Card source is linked

## Scheduling Algorithm
- [ ] FSRS algorithm implemented correctly
- [ ] SM-2 fallback available
- [ ] Algorithm abstraction layer works
- [ ] Algorithm is swappable without data loss
- [ ] Stability/difficulty calculations correct
- [ ] Interval scheduling correct

## Review Session
- [ ] Due cards retrieved correctly
- [ ] Card flip interaction works
- [ ] Rating submission works (again/hard/good/easy)
- [ ] Card state updates correctly after review
- [ ] Next review date calculated correctly
- [ ] Review history recorded

## API
- [ ] SRS API endpoints implemented
- [ ] Authentication enforced
- [ ] Response format correct

## Statistics
- [ ] Reviews per day tracked
- [ ] Retention rate calculated
- [ ] Card state distribution displayed
- [ ] Review forecast available

## Testing
- [ ] Scheduling algorithm tests pass
- [ ] Review workflow tests pass
- [ ] Edge cases tested (overdue cards, new cards)

## Gate Approval
- [ ] All mandatory items pass
- [ ] Approved to proceed to Phase 06
