# Phase 07 — Gamification Prompts

## Objective
Implement gamification features: XP, streaks, achievements, daily goals, milestones.

## Prerequisites
- Phase 04 complete (learning engine)
- Progress tracking operational

## Prompt Sequence

### Prompt 07-01: Gamification Architecture
```
Design the gamification system architecture.
Define: XP economy (what earns XP, how much),
level progression curve, streak rules,
achievement categories and criteria, daily goal system.
Review existing gamification code in both repositories.
```

### Prompt 07-02: XP & Levels
```
Implement the XP and level system.
Define XP awards: lesson completion, quiz scores, reviews, streaks.
Implement level progression with XP thresholds.
Build XP display and level-up notifications.
```

### Prompt 07-03: Streaks & Daily Goals
```
Implement streak tracking and daily goals.
Define what counts as daily activity.
Implement streak freeze/grace period if appropriate.
Build daily goal setting and progress display.
```

### Prompt 07-04: Achievements
```
Implement the achievement system.
Define achievement categories: learning, review, streak, exploration.
Implement achievement unlock detection.
Build achievement gallery UI.
Implement achievement notifications.
```

### Prompt 07-05: Gamification Dashboard
```
Build the gamification dashboard showing:
XP and level, current streak, daily goal progress,
recent achievements, milestones.
Implement gamification API endpoints.
Write gamification tests.
```
